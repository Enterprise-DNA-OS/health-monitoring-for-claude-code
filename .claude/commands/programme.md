# programme

One exposure group's programme: which tests, for which hazard, how often, and whether the law or the practitioner sets the interval.

Run `node scripts/health.mjs programme <group>`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Say plainly which intervals come from the law and which from the practitioner.
