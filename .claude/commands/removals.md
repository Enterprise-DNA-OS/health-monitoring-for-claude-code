# removals

Every removal from lead risk work: when, why, when the regulator was told, and the return with the doctor who cleared it.

Run `node scripts/health.mjs removals`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Flag any removal the regulator has not been told about.
