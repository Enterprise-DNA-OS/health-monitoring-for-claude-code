# disclosures

Who a worker's reports have been given to (other than the worker and the regulator), and the written consent behind each.

Run `node scripts/health.mjs disclosures [<worker>]`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Name any disclosure that relied on consent and its date.
