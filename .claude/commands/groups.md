# groups

Every exposure group (or --employer=<employer>): workers in it and its programme.

Run `node scripts/health.mjs groups [--employer=<employer>]`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Name any group with no programme.
