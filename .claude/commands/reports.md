# reports

Every test with its report duties: report obtained, worker's copy, regulator's copy, and where it stands. --open hides finished ones.

Run `node scripts/health.mjs reports [--open]`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Regulator copies owed first, then reports not obtained, then workers without their copy.
