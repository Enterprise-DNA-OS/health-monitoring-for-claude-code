# employer

Everything about one employer: its exposure groups and their programmes, tests not current, and reports not done.

Run `node scripts/health.mjs employer <employer>`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Lead with reports not done and tests overdue.
