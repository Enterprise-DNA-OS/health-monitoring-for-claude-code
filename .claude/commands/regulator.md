# regulator

Record that a copy of the report went to the regulator, with their reference (NZ reg 41, AU r 376 and r 413).

Run `node scripts/health.mjs regulator <ref> --reference="<their reference>" [--date=YYYY-MM-DD] --actor="<your name>"`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Never invent a reference. Ask for it.
