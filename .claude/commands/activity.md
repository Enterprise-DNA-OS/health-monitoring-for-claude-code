# activity

The activity log for the last 7 days (or --days=N): who did what.

Run `node scripts/health.mjs activity [--days=N]`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
