# employers

Every employer: region, currency, contact, active workers, overdue tests and what they owe.

Run `node scripts/health.mjs employers`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Point at the employer with the most overdue tests.
