# worker-copy

Record that the worker was given a copy of their report (NZ reg 39, AU r 375).

Run `node scripts/health.mjs worker-copy <ref> [--date=YYYY-MM-DD] --actor="<your name>"`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Offer `/draft-worker-letter` first if it has not been written.
