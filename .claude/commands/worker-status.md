# worker-status

Mark a worker as left (or active again) with the reason. Their groups close, every record stays, and the exit tests their programme offers are listed.

Run `node scripts/health.mjs worker-status <worker> --status=<left|active> --reason="<reason>" [--date=YYYY-MM-DD] --actor="<your name>"`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Offer the exit tests listed.
