# dna-tests

Every drug and alcohol test: reason, sample, screen, lab result, the result that can be reported, and where it stands. --open hides finished ones.

Run `node scripts/health.mjs dna-tests [--open]`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Never call a non-negative screen a positive. Use the reportable_result column.
