# removal-reported

Record that the regulator was told about a removal from lead risk work (r 415(2)).

Run `node scripts/health.mjs removal-reported <removal ref> --reference="<their reference>" [--date=YYYY-MM-DD] --actor="<your name>"`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Never invent a reference.
