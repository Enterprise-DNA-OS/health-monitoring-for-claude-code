# invoice-paid

Record that an invoice was paid.

Run `node scripts/health.mjs invoice-paid <invoice> [--date=YYYY-MM-DD] --actor="<your name>"`. Add `--json` when you need every field. Resolve the worker, employer, group or test by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Confirm the date the money arrived.
